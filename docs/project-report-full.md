## 一、项目背景与痛点

### 1.1 行业背景

数字时代，个人信息泄露风险持续高发。日常社交分享、工作沟通、小微经营中，截图与文本的敏感信息泄露已成为普遍民生痛点。同时，AI 图像还原技术（超分、Inpainting）快速普及，传统简单马赛克已无法保障信息安全——研究表明，8px 以下马赛克可被 AI 模型高概率还原。

### 1.2 三大核心痛点

| 群体 | 痛点 | 现状 |
|------|------|------|
| **普通网民** | 社交晒图/工作传截图时手动打码效率低、易遗漏；普通马赛克可被 AI 反向还原 | 缺乏零门槛工具 |
| **小微经营者** | 个体电商、商户处理订单和客服记录时，缺乏低成本的客户信息脱敏工具 | 面临合规风险 |
| **市场供给** | 专业脱敏工具门槛高、收费贵（月费数百至数千元） | 面向大众的产品供给不足 |

### 1.3 "息壤杯"赛道契合度

本项目精准契合惠民赛道「**轻量化、易落地、普惠实用**」的评审导向：纯软件产品、无需硬件资源、小团队可完成、直接面向大众日常场景。

## 二、产品定位与核心功能

### 2.1 产品定位

> 一款面向普通网民、小微商家、校园群体的 **零门槛 AI 隐私脱敏工具**。以网页端/微信小程序为载体，一键完成图片、文本中敏感信息的智能识别与安全脱敏。打造**普惠、实用、有温度**的个人隐私保护产品。

**Slogan**：上传 → 脱敏 → 安全分享，三步守护你的隐私。

### 2.2 三大核心功能

#### 功能一：图片智能脱敏

- **智能识别**：基于 PaddleOCR + YOLOv8，自动识别身份证号、手机号、住址、银行卡号、人脸、快递单号等 **10 余类敏感元素**
- **三种脱敏模式**：
  - 像素化（马赛克）：通用打码，观感友好
  - 高斯噪点混淆：强模糊 + 纹理感知噪声，抗 AI 去噪
  - ⭐ **不可逆像素替换**（核心创新）：种子哈希驱动的像素重排 + 伪随机值注入，**信息论级别不可逆**
- **双模式运行**：本地处理（图片不出设备）/ 精准增强（GPU 精准识别），用户自主选择

#### 功能二：文本批量脱敏

- 粘贴聊天记录、订单文本、文档片段
- 前端本地正则引擎自动检测 10+ 类敏感信息
- 高亮标注 → 一键掩码 → 复制
- 支持**自定义敏感词库**，适配工作、经营等不同场景
- 格式保留（如身份证保留前3后4位）

#### 功能三：⭐ 脱敏强度检测（特色功能）

- **依托信息安全专业能力**的核心差异化功能
- 上传脱敏前后图片，自动评估 AI 还原风险
- 三维量化分析：**SSIM**（结构相似度）+ **PSNR**（峰值信噪比）+ **纹理熵**
- 输出综合风险评分（0-100）+ 风险等级（安全/警告/危险）+ 加固建议
- 形成「**脱敏 → 检测 → 加固**」完整安全闭环

## 三、技术实现方案

### 3.1 整体技术架构

| 层面 | 技术选型 | 说明 |
|------|---------|------|
| **前端** | uni-app (Vue 3 + TypeScript + Vite) | H5 + 微信小程序一套代码 |
| **样式** | UnoCSS | 原子化 CSS，双端兼容 |
| **前端 OCR** | Tesseract.js v5 (WASM) | 浏览器端 OCR，本地模式用 |
| **后端** | Python FastAPI | 异步高性能 Web 框架 |
| **OCR 引擎** | PaddleOCR (GPU) | 中文识别准确率业界最优 |
| **目标检测** | YOLOv8-nano | 最轻量 YOLO 模型 (6MB) |
| **图像处理** | OpenCV + Pillow | 服务端图像操作 |
| **数学计算** | NumPy + SciPy + scikit-image | SSIM/PSNR 计算 |
| **部署** | Docker (CUDA) + Vercel | 后端容器化 + 前端免费托管 |

### 3.2 核心架构决策：「端侧优先 + 服务端增强」

```
本地模式：Tesseract.js OCR + Canvas 脱敏 → 图片完全不离开设备
精准模式：PaddleOCR GPU → 返回坐标 → 前端 Canvas 脱敏 → 图片不入库
```

**隐私保障三重奏：**
1. 图片仅在内存中处理，响应后立即释放，**不落盘存储**
2. 日志不记录请求体（防止图片数据泄漏到日志）
3. 用户可选择纯本地模式，**图片完全不出设备**

### 3.3 核心技术亮点

1. **不可逆像素替换算法**（核心创新）：基于 Fisher-Yates 重排 + SHA-256 种子哈希 + 多轮迭代，确保 AI 超分/Inpainting 模型无法重建原始像素梯度
2. **对抗性噪点设计**：高斯噪点混淆算法注入纹理感知的非均匀噪声，专门对抗 AI 去噪模型
3. **反还原检测引擎**：SSIM/PSNR/纹理熵 三维量化评估，将脱敏安全性从"感觉"变为"数据"

### 5.1 社会价值

| 场景 | 适配方式 |

### 5.3 长远拓展方向
