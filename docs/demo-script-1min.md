## 录制前必读（3 条）

1. **先热身**：打开前端随便传张图识别一次，让 PaddleOCR 模型进缓存，录屏时别拍到 3~5s 的白屏加载。
2. **提前把脱敏选项调好**：脱敏方式选「不可逆替换 ⭐」、强度 70%、保护等级点「等级3」，省得录到一半去点选项。
3. **录屏规格**：Win+G（Xbox Game Bar）或手机横屏，**1080p、16:9、60 秒内**；画面要能被压缩到 <100MB（录得越短越省，够 58s 就够）。
4. **配音**：你自己口播。用耳机/安静房间，别贴脸喷麦；念错就整句重录，剪辑接得上。
