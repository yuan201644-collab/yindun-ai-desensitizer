## 二、图片智能脱敏（核心功能）

### 2.1 OCR 文本识别

**实现方式**：
- **云端模式**（推荐）：PaddleOCR GPU 推理 → 返回文本 + 坐标
- **本地模式**（隐私优先）：Tesseract.js WASM → 浏览器端推理

**识别能力**：
- 中文 + 英文 + 数字混合
- 倾斜文本校正
- 密集文本区分

**可调整参数**：
- 检测置信度阈值（`DET_DB_THRESH`）
- 识别批处理数（`REC_BATCH_NUM`）
- 最大文本长度（`MAX_TEXT_LENGTH`）

**⚠️ 预留扩展位置**：
- 在 `app/services/ocr_service.py` 中可替换 OCR 引擎
- 在 `app/core/config.py` 的 `SENSITIVE_PATTERNS` 字典中添加新模式
- 识别模型可升级（如 PaddleOCR v3 → v4）

### 2.2 目标检测

**实现方式**：YOLOv8-nano → GPU/CPU 推理

**检测目标**：
- 人脸（person）
- 证件（需微调自定义模型）
- 手机屏幕
- 票据/单据

**⚠️ 预留扩展**：
- 在 `DetectionConfig.SENSITIVE_CLASSES` 添加新类别
- 可替换为其他检测模型（YOLOv9、RT-DETR 等）
- 支持自定义微调模型路径

### 2.3 脱敏模式

| 模式 | 当前版本 | 可扩展方向 |
|------|---------|-----------|
| **像素化** | 矩形等大马赛克 + 随机扰动 | 自适应块大小、圆角马赛克、渐变马赛克 |
| **高斯噪点混淆** | 多轮高斯模糊 + 噪声注入 | Perlin 噪声、分形噪声、纹理替换 |
| **不可逆替换** ⭐ | Fisher-Yates 重排 + 伪随机注入 | 混沌映射、元胞自动机、多方安全计算的像素共享方案 |
| **字符替换** | 格式感知掩码 | 同态加密保留格式、假名替换 |

**⚠️ 新增算法**：
1. 在 `app/core/algorithms/` 下新建 `.py` 文件
2. 继承 `BaseDesensitizer` 类
3. 在 `DesensitizerRegistry.register("name", Class)` 注册
4. 前端在 `canvas.ts` 的 `applyDesensitize()` 中添加对应 case

### 2.4 场景模板

**规划中的预设模板**（决赛阶段）：
- 🗨️ **聊天记录模式**：优先检测手机号、地址、身份证号
- 📦 **快递单模式**：优先检测快递单号、收件人、电话
- 🪪 **证件照模式**：全局检测 + 人脸高优先级
- 📊 **工作文档模式**：检测公司内部信息模式

### 2.5 批量处理

**规划中的功能**（决赛/赛后）：
- 多图上传 → 自动识别 → 统一脱敏设置 → 批量下载
- 适用场景：商家批量处理订单截图

## 三、文本智能脱敏

### 3.1 自动检测

**实现方式**：前端本地正则引擎（纯浏览器端，无网络请求）

**内置模式库**：
| 类别 | 示例 |
|------|------|
| 身份标识 | 身份证号、驾驶证号、护照号 |
| 联系方式 | 手机号、固话、邮箱、微信号、QQ号 |
| 金融信息 | 银行卡号、支付宝账号 |
| 位置信息 | 家庭住址、GPS 坐标 |
| 物流信息 | 快递单号、运单号 |
| 网络标识 | IP 地址、MAC 地址 |

**⚠️ 扩展方式**：在 `frontend/src/utils/sensitivePatterns.ts` 的 `DEFAULT_PATTERNS` 数组中添加新模式。

### 3.2 掩码处理

**掩码策略**（可配置）：
- 保留前 N 位 + 保留后 M 位（如 `138****1234`）
- 全掩码（如 `********`）
- 邮箱特殊规则（仅掩码用户名部分）

### 3.3 自定义敏感词库

**规划中（复赛）**：
- 用户可以添加自定义敏感词/正则
- 不同场景可切换不同词库
- 可选登录后云端同步词库

### 3.4 格式保留

- 掩码后保持与原文本相同长度
- 保留字母/数字/汉字的原有格式特征
- 可选生成假名替代（如随机生成合法格式的假身份证号）

## 四、脱敏强度检测（⭐ 特色功能）

### 4.1 多维度评估

| 指标 | 含义 | 计算方式 |
|------|------|---------|
| **SSIM** | 结构相似度 | `skimage.metrics.structural_similarity` |
| **PSNR** | 峰值信噪比 | `20*log10(255/sqrt(MSE))` |
| **纹理熵** | 局部信息残留 | 分块直方图熵平均 |

### 4.2 风险评分

- 加权综合评分（SSIM 50% + PSNR 25% + 纹理熵 25%）
- 0-100 分，分数越低越安全
- 三档风险等级：🟢 安全 (<30) | 🟡 警告 (30-60) | 🔴 危险 (>60)

### 4.3 加固建议

- 根据风险等级自动推荐加固方案
- 「一键加固」：自动提高脱敏强度并重新处理
- 比较不同算法的安全性（像素化 vs 高斯 vs 不可逆）

### 4.4 对抗性验证（规划中）

- 接入 Real-ESRGAN / SwinIR 等超分模型
- 尝试还原脱敏区域 → 对比还原效果
- 真正的"以 AI 测 AI"——用 AI 还原能力检验脱敏安全性
