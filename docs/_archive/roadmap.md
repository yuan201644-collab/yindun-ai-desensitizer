# 「隐盾」分阶段开发 Roadmap

## 总体时间线

```
2026年 7月        8月 (初赛)       9月 (复赛)        11月 (决赛)
    │                │                │                 │
    ├── 项目启动      ├── MVP 交付      ├── 功能完善       ├── 产品打磨
    │   · 技术调研    │   · 原型开发    │   · 新增功能     │   · 性能优化
```

## 阶段一：核心 MVP（初赛 | 2026年7月下旬 - 8月）

**目标：演示视频可用的图片脱敏原型**

### 开发任务清单

| 优先级 | 任务 | 产出 | 预估工时 |
|--------|------|------|---------|
| P0 | 项目脚手架搭建 | Vite + uni-app + FastAPI 框架跑通 | 2h |
| P0 | 图片上传 + Canvas 预览 | UploadZone 组件，拖拽/点击上传，预览渲染 | 3h |
| P0 | PaddleOCR 集成 | 后端 OCR 服务 (GPU)，中文文本检测+识别 | 4h |
| P0 | 敏感信息正则分类 | 10+ 类敏感模式识别与风险分级 | 2h |
| P0 | 像素化脱敏算法 | 前端 Canvas 实现 + 后端 Python 实现 | 3h |
| P0 | 高斯噪点脱敏算法 | 前端 + 后端双端实现 | 2h |
| P0 | 一键下载 | Canvas → Blob → download | 1h |
| P1 | 基础 UI/UX | 三步操作流程、暗色主题、响应式布局 | 3h |
| P1 | 文本脱敏基础版 | 粘贴文本 + 本地正则检测 + 掩码 | 2h |
| P2 | 项目文档 + 演示视频 | 完整文档 + 3-5分钟操作演示 | 4h |

### 可交付成果
- ✅ 可用 Web 原型（上传 → 自动识别 → 选择脱敏 → 下载）
- ✅ 后端 API 服务（GPU 推理）
- ✅ 3-5 分钟产品演示视频
- ✅ 完整项目汇报文档

---

## 阶段二：功能完善（复赛 | 2026年9月）

**目标：核心功能齐备，体验优化**

| 优先级 | 任务 | 说明 |
|--------|------|------|
| P0 | YOLO 目标检测集成 | 人脸/证件/票据实体检测，与 OCR 结果融合 |
| P0 | 不可逆替换算法 | 自研核心创新算法，信息论级别不可逆 |
| P0 | 脱敏强度检测引擎 | SSIM/PSNR/纹理熵 三维评估，风险评分系统 |
| P0 | 文本脱敏增强 | 批量处理、自定义敏感词库、格式保留 |
| P1 | 微信小程序 MVP | uni-app 编译微信小程序，核心功能可用 |
| P1 | 交互体验优化 | 区域手动调整、撤销/重做、批量区域操作 |
| P1 | 用户测试 | 邀请 5-10 人试用，收集反馈并迭代 |
| P2 | 预设场景模板 | 聊天记录模式 / 订单模式 / 证件照模式 / 快递单模式 |

### 可交付成果
- ✅ 图片+文本+检测三大功能完整可用
- ✅ 微信小程序可体验版本
- ✅ 用户测试报告 + 优化清单

---

## 阶段三：打磨落地（决赛 | 2026年10-11月）

**目标：产品成熟，方案完整**

| 优先级 | 任务 | 说明 |
|--------|------|------|
| P0 | 性能优化 | PaddleOCR INT8 量化、模型预热、前端加载优化 |
| P0 | 安全加固 | API 限流、文件类型深度校验、渗透测试 |
| P0 | 多场景适配 | 电信营业厅业务单据脱敏 Demo |
| P1 | 反还原检测增强 | 接入 Real-ESRGAN 做对抗性验证（如有 GPU 资源） |
| P1 | 落地推广方案 | 运营商合作方案、推广策略、用户增长计划 |
| P2 | 无障碍优化 | 屏幕阅读器支持、键盘导航 |

### 可交付成果
- ✅ 性能达标的产品（单图处理 < 5秒）
- ✅ 安全审计通过的代码
- ✅ 完整落地推广方案
