## 配音/字幕要点
- 语速：中速、稳，旁白总时长约 3 分 20 秒（口播词如上，不加戏）。
- 字幕卡在**画面关键动作后**出现（先做动作、再出字），别抢焦点。
- 冷启动白屏（镜头5）：先热身一张；或后期直接剪掉空白帧。
- 每播放一步，时间线已留 3–5s 缓冲，避免手忙脚乱。
- 若想压缩到 3 分钟内：合并镜头 2、3，删镜头 15。
